## 1.2 结构体逐段注释

```cpp
struct AhoCorasick {
    static constexpr int ALPHABET = 26;   // 只支持 a~z；其它字符 c - 'a' 会越界

    struct Node {
        int len;                          // 该节点代表的串长：虚根 = -1，真根 = 0，其余 = 深度
        int link;                         // fail 指针：当前串的最长真后缀（也在 trie 中的那个节点）
        array<int, ALPHABET> next;        // 转移表。建树时是 trie 边；work() 后缺边被补全为自动机转移
        Node() : len{0}, link{0}, next{} {}
    };

    vector<Node> tree;                    // tree[0] = 虚根，tree[1] = 真根（空串）

    AhoCorasick() { init(); }

    void init() {
        tree.assign(2, Node());           // 预先占好 0、1 两个特殊节点
        tree[0].next.fill(1);             // 虚根的 26 条转移全指向真根
        tree[0].len = -1;                 // 于是真根 len = 0，第一层字符节点 len = 1
    }

    int newNode() {
        tree.emplace_back();
        return tree.size() - 1;           // 新节点编号；节点 0 永远不会被分配
    }
```

要点：**节点 0 是"虚根"**。它的存在让根节点也能用统一公式算 fail：
`fail(son) = next[fail(x)][c]`。当 `x` 是真根时 `fail(1) = 0`，而 `next[0][c] = 1`，
所以根的儿子 fail 自然回到根，不需要特判。同时 0 被占用，使得 `next[x][c] == 0`
可以安全地表示"没有这条边"。

```cpp
    int add(const string &str) {
        int p = 1;                        // 从真根出发
        for (auto c : str) {
            int x = c - 'a';
            if (tree[p].next[x] == 0) {   // 无真实边（0 已被虚根占用，所以是安全的哨兵）
                tree[p].next[x] = newNode();
                tree[tree[p].next[x]].len = tree[p].len + 1;   // 串长 = 父串长 + 1
            }
            p = tree[p].next[x];          // 有边就复用（同一前缀只建一次）
        }
        return p;                         // 返回模式串终点编号，查询答案时用
    }
```

`add` 的职责只有"建 trie"，不碰 fail。**必须在所有 `add` 完成后再调用 `work()`**，
否则补全出来的转移会被后续 `add` 当成真实边而复用，建出错误的树。

```cpp
    void work() {                         // BFS 求 fail，并把转移表补全为自动机
        queue<int> que;
        que.push(1);                      // 从真根开始
        while (!que.empty()) {
            int x = que.front();
            que.pop();
            for (int i = 0; i < ALPHABET; i++) {
                if (tree[x].next[i] == 0) {
                    // 缺边：直接继承 fail 状态在同一字符上的转移。
                    // 这就是"补全自动机"，补完后 next(p, c) 是 O(1)，扫描文本时不必沿 fail 链跳。
                    tree[x].next[i] = tree[tree[x].link].next[i];
                } else {
                    // 有真实儿子：儿子的 fail = 父亲 fail 的同字符转移。
                    // BFS 保证 link[x] 深度更小、它的转移已经被补全，可以直接用。
                    tree[tree[x].next[i]].link = tree[tree[x].link].next[i];
                    que.push(tree[x].next[i]);
                }
            }
        }
    }
```

正确性依赖两点：
1. `len(link(x)) < len(x)`，所以 BFS 层序处理时 `link(x)` 一定已经处理过；
2. `next[0][*]` 全为 1（虚根兜底），所以根的儿子 `link` 落在真根上，不会指向 0。

```cpp
    int next(int p, int x) { return tree[p].next[x]; }  // work() 之后保证非 0，可直接走
    int link(int p)        { return tree[p].link; }     // fail 指针，用于 fail 树上累加
    int len(int p)         { return tree[p].len; }      // 节点串长，用来给 fail 树排序
    int size()             { return tree.size(); }      // 节点数 = 不同前缀数 + 2（有公共前缀时小于总长 + 2）
};
```

```cpp
    sort(order.begin(), order.end(), [&](int a, int b) { return ac.len(a) > ac.len(b); });

        cnt[ac.link(p)] += cnt[p];    // 把子树计数推给 fail 父亲，最终 cnt[x] = x 的 fail 子树加权大小

    for (auto &p : ends)
        cout << cnt[p] << endl;       // 模式串终点的 cnt 即它的出现次数（允许重叠）
}

```

### 原理串讲

1. **扫描阶段**：在补全后的自动机上走文本的每个前缀，停留的状态是"当前前缀的最长后缀，且是某个模式串的前缀"。给该状态 +1，表示"这个前缀贡献了一次"。
2. **fail 树**：`link` 把每个状态接到它的最长真后缀上，形成一棵以真根为根的树；状态 `x` 的 fail 祖先恰好是"所有是 `x` 所代表串的后缀、且出现在 trie 中的串"。
3. **累加阶段**：把 `cnt[p]` 推给 `link(p)`，相当于求 fail 树上的子树和。处理完 `p` 时 `cnt[p]` 已经是"经过 p 的所有文本前缀数"，也就是 `p` 所代表串的出现次数。
4. **为什么按 len 降序就够**：`link(p)` 严格更短，所以任何一条 fail 边都从大 len 指向小 len；降序即拓扑序。**省掉了显式 BFS 序数组**。
5. 模式串 `i` 的出现次数 = `cnt[ends[i]]`。相同模式串会 `add` 到同一终点，因此各自拿到同样的答案。

### 复杂度

| 阶段 | 复杂度 |
|---|---|
| 建 trie（所有模式串总长 `L`） | `O(L)` |
| `work()` | `O(26 · 节点数) = O(26L)` |
| 扫描文本（长度 `m`） | `O(m)` |
| 排序 + 累加 | `O(N log N)`，`N = 节点数 ≤ L + 2`（可换成按 len 计数排序做到 `O(N + maxLen)`） |
| 空间 | `O(26N)`（`array<int,26>` 每节点 104 字节） |

### 使用陷阱

- **只支持小写 `a~z`**，其它字符会越界写 `next`。
- **`work()` 只能调用一次**：第二次调用时所有 `next` 都非 0，继承出来的转移会被误当成真实儿子再次入队，导致队列爆炸。
- **`add` 必须在 `work` 之前全部完成**；`work` 之后再加串会走到补全出来的转移上，建出错误结构。
- `size()` 包含虚根 0 与真根 1，所以 `cnt` 开 `ac.size()` 刚好；`cnt[0]` 会吸收整棵树的总数，但 0 是虚根，不影响答案。
- 该模板只统计**次数**，不记录出现位置，也不去重；要位置/去重需另存 endpos 集合。
- 若不需要排序，也可以在 BFS 时记录层序、倒着累加，少一个 `log`。

# 二、String/Manacher.hpp

## 2.1 逐行注释

```cpp
auto manacher = [](string s) -> vector<int> {
    string str = "^#";                  // '^' 是左哨兵，'#' 是分隔符（二者都不能出现在原串中）
    for (auto &p : s)
        str += p, str += '#';           // 逗号运算符：先接字符，再接 '#'
    // 对 "abc" 得到 "^#a#b#c#"，长度 2n+2；s[k] 位于 str[2k+2]

    vector<int> len(str.size());        // 全 0 初始化；len[0] 不使用

    for (int i = 1, r = 1, mid = 0; i < str.size(); ++i)
    {
        // r 是已发现回文的最右边界（开区间），mid 是取得该边界的回文中心
        if (i < r)
            // 镜像优化：i 关于 mid 的对称点是 2*mid-i；
            // 初值取"镜像半径"和"到右边界距离"的较小者，保证不会高估
            len[i] = min(len[2 * mid - i], r - i);

        // 从初值继续向两边暴力扩展；第 1 次比较的是 str[i] 与自身（必然相等）
        while (str[i + len[i]] == str[i - len[i]])
            ++len[i];

        if (i + len[i] > r)             // 更新最右边界
            r = i + len[i], mid = i;
    }
    return len;
};
```

## 2.2 数组含义与下标换算

返回值 `len` 的长度为 `2n + 2`，下标 `0..2n+1`：

| 下标 `i` | 含义 |
|---|---|
| `0` | 左哨兵 `'^'`，未使用 |
| 奇数 `i = 2k+1` | 分隔符 `'#'`，对应原串中 `s[k-1]` 与 `s[k]` **之间**（偶数长度回文的中心） |
| 偶数 `i = 2k+2` | 原串字符 `s[k]`（奇数长度回文的中心） |

**`len[i]` 不是回文长度**，而是"以 `i` 为中心的极大回文在扩展串中的半径 + 1"
（因为 `while` 第一次比较 `str[i]` 与自身，必然成功，所以至少为 1）。换算公式：

```text
以 i 为中心的极大回文长度 L = len[i] - 1
起点 l = (i - len[i]) / 2      （i - len[i] 必为偶数，整除）
区间   = s[l, l + L - 1]
```

- `L` 的奇偶性由中心决定：偶数下标（字母中心）→ 奇数长度；奇数下标（分隔符中心）→ 偶数长度。
- 若要统计"回文子串出现次数"，每个中心的贡献是 `(L+1)/2`（字母中心）或 `L/2`（分隔符中心），**不是** `L`。
- 最长回文长度 = `max(len) - 1`。

### 取答案示例

```cpp
string s;
cin >> s;
auto len = manacher(s);

int best = 0;
for (int x : len)
    best = max(best, x - 1);
cout << best << endl;                 // 最长回文子串长度

// 取具体区间（以某中心为例）：
// int L = len[i] - 1, l = (i - len[i]) / 2;
// 回文即 s.substr(l, L)
```

## 2.3 正确性要点

1. **两端哨兵**：左端 `'^'` 与任何字符/分隔符都不相等，`while` 碰到它必然停下，保证 `i - len[i] >= 0` 不越界；
   右端依赖 `std::string` 在 `str[str.size()]` 处返回 `'\0'`（C++11 起合法且只读），同样必然失配。
   因此要求 `'^'` 和 `'#'` 都不出现在原串里；若原串可能含任意字节，需换两个不冲突的哨兵。
2. **镜像初值是保守的**：标准写法用 `min(p[2*mid-i], r-i)`（`p` 为不含中心的半径），此处因为 `len = p + 1`，
   `min(len[2*mid-i], r-i)` 比理论最优初值最多小 1。它**只会低估、不会高估**，`while` 至多多比较一次，
   复杂度与正确性都不受影响。
3. **`r` 单调不减**：每次只在 `i + len[i] > r` 时更新，所以总扩展次数是 `O(n)`。
4. **`mid` 的有效性**：`i < r` 时镜像下标 `2*mid-i` 落在 `[0, i)`，一定已被计算过，不会读到未初始化值。

## 2.4 复杂度与使用方式

- 时间 `O(n)`，空间 `O(n)`（返回数组 `2n+2`）。
- 这是**片段式**代码（`auto manacher = ...`），依赖外部已有 `bits/stdc++.h` / `using namespace std`；
  放在 `solve()` 里或改成普通函数都可以。lambda 按值接收 `string`（会拷贝一份原串，通常可接受）。

# 三、对拍/dp.sh

## 3.1 逐行注释

```bash
g++ -O2 data.cpp -o data.out      # 数据生成器
g++ -O2 ans.cpp  -o ans.out       # 标准/暴力解
g++ -O2 test.cpp -o test.out      # 待测解

N=100                             # 默认对拍轮数

if [ "${1}" != "" ]; then         # 第一个参数可覆盖轮数：bash dp.sh 500
    N=${1}
fi

cnt=0
while [ ${cnt} -lt ${N} ]; do      # 变量未加引号，N 非数字时会报 test 错误
    cnt=$((cnt + 1))
    echo 第 ${cnt} 组

    ./data.out >data.txt                 # 造一组输入
    ./ans.out <data.txt >ans.txt         # 标准答案
    ./test.out <data.txt >test.txt       # 待测输出

    if ! diff ans.txt test.txt; then     # 有差异：diff 会把不同行打印出来
        echo "Wrong"
        exit 0                           # 注意：错误时返回码仍是 0
    fi
done
```

## 3.2 执行流程

```text
编译三个 .cpp
   ↓
data.out → data.txt
   ↓            ↓
ans.out       test.out
   ↓            ↓
ans.txt       test.txt
   ↓            ↓
      diff 比较
   相同 → 下一轮（默认 100 轮）
   不同 → 打印差异 + "Wrong" + 退出（保留现场文件便于调试）
```

## 3.3 与 `dp.bat` 的对应关系

仓库里已跟踪的 `对拍/dp.bat` 是 Windows 版本，`dp.sh` 是它的精简 sh 移植：

| 项目 | `dp.bat` | `dp.sh` |
|---|---|---|
| 产物名 | `data.exe / ans.exe / test.exe` | `data.out / ans.out / test.out` |
| 输入/输出文件 | `input.txt / ans_out.txt / test_out.txt` | `data.txt / ans.txt / test.txt` |
| 运行失败检测 | `if errorlevel 1 goto :fail` | 无 |
| 编译失败检测 | `|| goto :fail` | 无（`set -e` 也没开） |
| 对拍失败 | 打印三份内容 + 置失败标志 | 只 `diff`，`echo Wrong`，`exit 0` |
| 清理 | 删除 `.exe` | 不清理（保留 `.out` 与 `.txt`） |
| 参数 | `%~1` | `${1}` |

## 3.4 可改进点

1. **缺少 shebang**：文件以 `g++` 直接开头，`./dp.sh` 需要执行位且没有解释器行；建议加 `#!/usr/bin/env bash`，或统一用 `bash dp.sh` 调用。
2. **错误码**：对拍命中差异时 `exit 0`，在 CI / `make` 里无法感知失败；建议改成 `exit 1`。
3. **不检查编译/运行错误**：编译失败时会继续跑上一次的旧二进制，出现"改了代码却没生效"的假象；建议 `set -euo pipefail` 或逐条 `|| exit 1`。
4. **`[ ${cnt} -lt ${N} ]` 未加引号**：`N` 为空或非数字时 `test` 会报错；可写成 `while [ "$cnt" -lt "$N" ]` 并校验参数。
5. **每次运行都重新编译**：对本机对拍问题不大；如果数据量大，可加"源文件比二进制新才编译"的判断。
6. **固定随机种子**：`data.cpp` 若固定种子，同一组数据会重复；可让脚本传入 `$RANDOM`/`seed` 参数（`dp.bat` 也没有）。

### 最小改进版（可直接替换）

```bash
#!/usr/bin/env bash
set -euo pipefail

N=${1:-100}

g++ -O2 data.cpp -o data.out
g++ -O2 ans.cpp  -o ans.out
g++ -O2 test.cpp -o test.out

for ((cnt = 1; cnt <= N; ++cnt)); do
    echo "第 $cnt 组"
    ./data.out > data.txt
    ./ans.out  < data.txt > ans.txt
    ./test.out < data.txt > test.txt
    if ! diff -u ans.txt test.txt; then
        echo "Wrong"
        exit 1
    fi
done
```
